= Extensions for arc42

Optional, additive extensions for the https://arc42.org[arc42] template.
Each extension adds fields or subsections to an existing arc42 section;
it never renames, removes or replaces one.

== Principles
* Additive only: attaches to an existing arc42 section
* Ignorable: a document stays valid arc42 without it
* Plain text: AsciiDoc source, no tooling required
* One concern per extension, versioned independently

== Extensions

|===
|Extension |Attaches to |Purpose
|link:extensions/triggers/EN/SPEC.adoc[triggers] |§9, §11 |Conditions that force a decision to be revisited
|===

== Adoption
Declare usage in §1 of your document and link to a tagged version, e.g.:
`Extensions used: triggers v1.0.0`
