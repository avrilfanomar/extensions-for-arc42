= Extensions for arc42

Optional, additive extensions for the https://arc42.org[arc42] template.
Each extension adds fields or subsections to an existing arc42 section;
it never renames, removes or replaces one.

== Principles
* Additive only: attaches to an existing arc42 section
* Ignorable: a document stays valid arc42 without it
* Plain text: AsciiDoc source, no tooling required
* One concern per extension, versioned independently
* Concept separate from implementation: SPEC → binding → implementations
* Dependencies are declared

== Implementations

link:implementations/reference-checker/[reference-checker]:: Python 3.10+ command-line tool for validating documents and checking revisit status. Standard library only, Apache-2.0 licensed.

== Adoption

Declare usage in §1 of your document, e.g.:

----
Extensions used: links v0.1.0, triggers v0.1.0
----

For production use, reference a tagged release once v1.0.0 is published.
